# virtual_lab know-how documents

Each other `.md` file in this directory is a know-how document: advice on how to do a kind of analysis, which the agents are told of and, when a task suits one, given in full. They are loaded with Biomni's own loader, in the same format as Biomni's documents (`virtual_lab/sandbox/biomni_package/biomni/know_how`), and offered after them. This file is not loaded, because its name is all capitals.

A document has a title (the first `# ` line), a `## Metadata` section that includes a `**Short Description**:` (the one or two sentences the retriever sees, so name what it covers in the words a task would use), a license, and whether commercial use is allowed. Write practice that holds for any data of the kind, and leave out answers to particular questions and particular datasets.
